# PagePilot visual system

Reading this as: product landing + auth that should feel like **iPhone / iOS** — Apple HIG, not purple SaaS, not a print studio.

## Words

- Clear, generous, physical
- Essence: **iOS grouped interface**

## Tokens

| Token | Value | iOS analog |
|---|---|---|
| `--bg` | `#F2F2F7` | systemGroupedBackground |
| `--surface` | `#FFFFFF` | secondarySystemGroupedBackground |
| `--ink` | `#1C1C1E` | label |
| `--mute` | `rgba(60,60,67,.60)` | secondaryLabel |
| `--line` | `rgba(60,60,67,.12)` | separator |
| `--accent` | `#007AFF` | systemBlue |
| Type | `-apple-system`, PingFang SC | SF Pro |

## Layout

- Large Title at the top of home / auth
- Grouped lists (white inset groups, 10–12px continuous corners)
- Primary actions: full-width system-blue rounded rect
- Cards like App Store: image, title, footnote — no glass mesh, no hairline newspaper rules
